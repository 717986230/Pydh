# 画面提示词工艺（全系列最高优先级，两季通用）

用户原话：「画面，人物，打斗动作，场景，画面提示词一定要好好写。」每镜提示词按本指南写，写不好不许生成；合成前验片按本指南挑错。

## 一、每镜提示词的四段结构（缺一不可，顺序固定）
1. **场景段**：地点 + 时间 + 陈设 + 幕布光影。例：「龙虎山山门前，清晨，石牌坊与松树剪影，幕布上晨光斜照」。同一地点跨镜复用同一套场景词（见第三节场景清单）。
2. **人物段**：逐字引用 characters.md 的造型锁定词（服饰颜色、发型、标志物），并写清站位、朝向、彼此距离。例：「史进居右，红巾束发，赤膊，身上九条青龙；面朝左侧的陈达，两人相隔三步」。
3. **动作段**：写动作链，不写静态形容词。用「谁先动 → 怎么做 → 对方如何反应 → 收势」的顺序，一镜只装一条动作链。情绪靠姿态（昂首、后退半步、手指发抖），不写抽象词（「很生气」无效）。
4. **镜头段**：景别（全景/中景/近景）+ 画面后缀（WORKFLOW 的上色皮影后缀逐字粘贴，不得改写缩减）。

## 二、自包含原则
生成器没有记忆：每一镜提示词必须写全人物外观与场景，禁止「同上」「同前」「他」指代不清。角色第几次出场都要带全套锁定词。

## 三、场景清单制
每集分镜时先定场景清单：本集出现的每个地点写一段标准场景词，存入 storyboard.md 顶部；全集同地点镜头共用这段词，只改人物与动作。跨集复用的地点（如梁山、史家村）沿用旧描述，保证系列一致性。

## 四、打斗专项
- 一招一镜：一镜只写一组攻防（如「陈达挺枪直刺面门 → 史进侧身让过，棒尾横扫其手腕 → 陈达撒手，枪落地」），不贪多。
- 写清兵器轨迹（从哪来、往哪去）与发力方向，双方都要有反应动作。
- 景别用全景/中远景，人物全身入画；不写近景特写与伤口。
- 速度感靠姿态与幕布残影，不靠血腥；倒地、被擒等结果用姿态呈现。
- 范例（金标准，第2回第14镜）：
「场景：史家村庄前空地，白日，庄门与栅栏在后景，尘土微扬。人物：史进居右，红巾束发，赤膊，九条青龙盘绕上身，持齐眉棍；陈达居左，红脸，褐色山贼短打，骑一匹枣红马，挺长枪。动作链：陈达催马挺枪直刺史进胸口 → 史进侧身闪过枪尖，棍头顺势压住枪杆往下沉 → 陈达双手脱枪、身子一歪从马鞍滑落，史进棍尖停在其肩前收势。镜头：全景，两人一马全身入画。Traditional Chinese shadow puppetry with COLORED translucent dyed-leather puppets (deep red, ochre, amber yellow, green), coarse simple folk shapes, rough hand-cut edges, minimal fine detail, plain pale paper screen background, visible bamboo control rods, side view, smooth continuous jointed puppet motion, vertical 9:16, no text, no watermark」

## 五、对白版额外要求
说话者面朝听者、下颌随说话开合；听者有微反应（点头、后仰、握拳）；双人同框为主，避免背对镜头说话；台词长的镜头给说话者留中景，方便字幕与口型观感。

## 六、负面清单（每镜默念检查）
画面文字/水印、现代物品（眼镜、拉链、腕表）、写实皮肤质感、真人面孔、多余手指或肢体、人物造型与锁定词不符、场景与清单不一致、血腥伤口特写。出现即在 manifest 标注重生成，不许带病合成。

## 七、工作方法
- 先写满四段再发生成调用；提示词原文存入 manifest，改词才重生成（与清单制一致）。
- 每集生成完先看联系表对照本指南逐项挑错：造型、场景、动作可读性、负面清单，通过才进合成。

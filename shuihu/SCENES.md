# 水浒传 · 场景库（跨集复用，同地点必须用同一段场景词）
- 龙虎山山道：蜿蜒石阶山道，松林两侧，远处道观飞檐，幕布晨雾
- 上清宫伏魔殿：殿宇深处，石碑居中，香烟缭绕，光线幽暗
- 东京街市：汴梁街市，两侧店铺幌子，人流如织，日光
- 太尉府大堂：高堂梁柱，案几居中，两侧甲士林立
- 史家村庄院：大宅院落，练武场，兵器架，枣树一株
- 山野土路：黄土路蜿蜒，远山，孤树（赶路过场通用）
- 金殿宝座：皇宫大金殿内，丹墀之上宝座居中，龙柱华表两侧，殿门日光斜照（第2回新增）
- 月夜官道：夜晚月光清冷，官道蜿蜒，东京城门剪影居后景，远山孤树（第2回新增）
- 夜火史家村：夜晚火光冲天，庄院燃起大火，火星四溅（第3回新增）
- 少华山寨：聚义厅，虎皮交椅，旗帜林立（第3回新增）
- 渭州茶坊：街口小小茶坊，几副座位，酒幌子（第3回新增）
- 渭州街市：六街三市，人流如织，街头卖艺圈（第3回新增）
- 潘家酒楼：州桥下酒楼，望竿酒旆高挑，阁子雅间（第3回新增）
- 鲁家客店：东门里客店，院落房门，清晨天色微明（第3回新增）
- 状元桥肉铺：两间门面，两副肉案，悬挂三五片猪肉（第3回新增）
- 代州雁门县街口：十字街口，人丛围看榜文（第3回新增）
